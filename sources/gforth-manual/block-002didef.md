#### 8.2.1 Implementation Defined Options

<span id="index-implementation_002ddefined-options_002c-block-words"></span> <span id="index-block-words_002c-implementation_002ddefined-options"></span>

  - *the format for display by `LIST`:*  
    <span id="index-LIST-display-format"></span>
    
    First the screen number is displayed, then 16 lines of 64 characters, each line preceded by the line number.

  - *the length of a line affected by `\`:*  
    <span id="index-length-of-a-line-affected-by-_005c"></span> <span id="index-_005c_002c-line-length-in-blocks"></span>
    
    64 characters.
