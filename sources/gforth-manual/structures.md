### 5.22 Structures

<span id="index-structures"></span> <span id="index-records"></span>

This section presents the structure package that comes with Gforth. A version of the package implemented in Standard Forth is available in `compat/struct.fs`. This package was inspired by a posting on comp.lang.forth in 1989 (unfortunately I don’t remember, by whom; possibly John Hayes). A version of this section has been published in M. Anton Ertl, [Yet Another Forth Structures Package](http://www.complang.tuwien.ac.at/forth/objects/structs.html), Forth Dimensions 19(3), pages 13–16. Marcel Hendrix provided helpful comments.
