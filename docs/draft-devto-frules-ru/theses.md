## §6 Postfix / IR / «из пушки по воробьям»

- Обратная польская нотация чужда «пишущим напрямую» — пример `(a+b)*c`.

- Pipeline: ТЗ → IR → transpiler → gforth.
- **Голая нейросеть не программирует** — система с tools.
